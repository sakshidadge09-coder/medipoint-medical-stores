# Medipoint Medical Store Management System 

A web-based admin system for managing a medical store.

## Features
- Admin login
- Billing
- Stock management
- Supplier management
- Reports

## Technologies Used
PHP, MySQL, HTML, CSS, XAMPP

## How to Run
1. Install XAMPP and start Apache and MySQL.
2. Copy this project folder into `htdocs`.
3. Open phpMyAdmin and create a database named `medical_store_db`.
4. Import the `.sql` file from this repository.
5. Open `localhost/medipoint-medical-stores` in a browser.

Note: Default XAMPP settings are used (username: root, empty password). Change these in `config/database.php` if your MySQL setup differs.
